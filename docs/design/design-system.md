# TANICO Design System

## Design direction

Use Material Design 3 with a natural green-and-brown palette representing organic agricultural waste, soil, and sustainable use.

## Color tokens

| Token | Hex | Intended use |
|---|---|---|
| Primary / Forest Green | `#386641` | Primary actions, selected navigation |
| Secondary / Earth Brown | `#8D6E4C` | Supporting actions and accents |
| Tertiary / Fresh Green | `#6A994E` | Positive highlights |
| Background / Warm Cream | `#F7F5EF` | Main app background |
| Surface / Soft White | `#FFFFFF` | Cards and sheets |
| Text Primary | `#292D25` | Main text |
| Text Secondary | `#6F6B60` | Supporting text |
| Outline / Natural Beige | `#D8D1C3` | Borders and dividers |
| Error | `#BA1A1A` | Error states |

## Components

Prefer Material 3 components:
- TopAppBar
- NavigationBar
- NavigationBarItem
- FilledButton and OutlinedButton
- Card
- TextField
- FilterChip and InputChip
- ModalBottomSheet
- AlertDialog
- Badge
- ProgressIndicator
- Snackbar

## Navigation

Shared destinations:
- Beranda
- Notifikasi
- Pembelajaran
- Profil

Role-specific home content:
- Buyer: marketplace/catalog.
- Seller: store management and seller dashboard.

## Guidelines

- Maintain readable contrast.
- Use consistent spacing, shape, typography, and component states.
- Include loading, empty, error, disabled, and success states.
- Avoid unnecessary gradients and overly saturated colors.
- User-facing copy should be Bahasa Indonesia.
